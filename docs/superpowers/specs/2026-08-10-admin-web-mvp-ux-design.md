# 관리자웹 MVP UI·UX 설계

## 목표

지도 검수와 iframe 지도 편집을 제외한 관리자웹을, 시설 관리자가 안내 가능한 실내 지도를 구축·운영할 수 있는 배포 수준의 화면으로 정비한다.

## 범위와 우선순위

이 문서는 1차 MVP 서비스 정책을 최우선 원천으로 삼는다. 기존 관리자 기능 명세서는 이미 구현된 CRUD 범위와 화면 항목을 확인하는 보조 자료로만 사용한다. 정책이 충돌할 경우 MVP와 최신 지도 편집 분리 원칙을 우선한다.

포함 범위는 다음과 같다.

- 가입 신청, 로그인, 승인 대기·거절 안내, SUPER ADMIN의 승인·거절
- 대시보드의 건물·층 현황과 최근 건물
- 건물 등록·수정·삭제, 즐겨찾기 우선 목록
- 층 등록·수정·삭제와 major 자동 표시
- 설계도 PNG 업로드와 자동 추출 상태 표시
- 랜드마크의 이름, 별칭, 문 방향 등 의미 정보 관리
- 비콘의 MAC, major/minor, 유형, 배터리, 수직 연결자 바인딩 관리
- 건물 단위 수직 연결자 선언과 층별 결손 검수
- 설치 가이드라인 조회, 설정·계정 화면

다음 범위는 제외한다.

- iframe 내부의 마스크, 축척, 경로노드, 지도 위 랜드마크·비콘 위치 편집
- 지도 편집 알고리즘, 경로노드 생성, 지도 데이터 저장 방식의 변경

## 작업 흐름

층의 설정 과정은 다음 순서로 표현한다.

1. 층 등록 — 관리자웹
2. 설계도 업로드 — 관리자웹
3. 지도 편집 — iframe
4. 정보 입력 — 관리자웹
5. 층간 연결 — 관리자웹
6. 승인 — 관리자웹

관리자웹은 지도 편집 단계에 외부 편집 진입 버튼과 서버가 반환한 상태만 보여준다. iframe 내부의 작업 순서나 편집 상태를 중복 구현하지 않는다.

관리자웹은 iframe에 `floorId`, `imageUrl`, `editorState`를 전달할 수 있어야 한다. 지도에서 반환되는 랜드마크·비콘은 표시 이름이나 순번이 아닌 삭제 후에도 바뀌지 않는 `landmarkId`와 `beaconId`로 연결한다.

## 정보 구조

- 사이드바: 대시보드, 건물 관리, 승인 관리, 설치 가이드라인, 설정, 계정
- 대시보드: 건물 수, 층 수, 안내 가능 건물 수, 설정 진행 건물 수, 최근 건물 목록. ‘오늘 할 일’ 영역은 두지 않는다.
- 건물 목록: 카드 목록으로 표시하고 즐겨찾기 우선, 이후 등록일 내림차순을 사용한다.
- 건물 상세: 기본 정보, 층 목록, 수직 연결자 관리로 구성한다.
- 층 목록: 층수 오름차순으로 표시한다. 각 행은 서버 계산 상태와 다음 단계 진입점을 제공한다.
- 비콘 목록: minor 오름차순으로 표시한다.
- 승인 대기 목록: 가입 신청일 내림차순으로 표시한다.

## 화면 UX 원칙

공통 레이아웃은 고정 사이드바, 상단 사용자 메뉴, 브레드크럼, 최대 폭 콘텐츠 영역으로 통일한다. 목록·폼·상세 화면은 동일한 제목, 주요 CTA, 보조 동작 배치를 사용한다.

층별 상태는 프론트에서 계산하지 않고 서버 응답을 그대로 표시한다. 상태 표현은 색상과 텍스트를 함께 사용한다. 최소 상태는 설계도 미업로드, 축척 미설정, 검수 필요, 비콘 미등록, 연결자 결손, 안내 가능이다. API 확정 전에는 상태 코드·색상·문구의 최종 매핑을 확인한다.

입력 화면은 필수값, 입력 형식, 자동 계산값, 파일 조건을 해당 필드 바로 가까이에 배치한다. major는 층수에서 자동 계산해 읽기 전용으로 보여준다. 연결자 바인딩은 자유 입력이 아닌 드롭다운 선택만 허용한다.

랜드마크는 지도 위치가 아니라 이름·별칭·문 방향을 관리한다. 비콘은 지도 위치가 아니라 MAC, major/minor, 유형, 배터리와 연결자 참조를 관리한다.

## 상태 및 오류 처리

- 로딩: 목록과 상세 정보의 구조를 유지하는 스켈레톤을 표시한다.
- 빈 상태: 이유를 설명하고 해당 리소스를 등록하는 CTA를 제공한다.
- 저장 성공: 저장 후 토스트로 완료를 알리고, 목록·상세의 최신 상태를 즉시 반영한다.
- 유효성 오류: 필드 단위 오류 문구와 오류 필드로의 포커스 이동을 제공한다.
- 서버 오류: 원인 안내, 재시도 버튼, 데이터 보존을 제공한다.
- 삭제: 대상 이름과 영향 범위를 명시한 확인 모달을 거친다.
- 권한: 미인증 사용자는 로그인으로 이동한다. ACTIVE + ADMIN만 관리자웹에 진입하며 PENDING·REJECTED에는 전용 안내 화면을 제공한다.

## 검증 기준

- 지도 편집 관련 페이지와 컴포넌트의 동작은 변경하지 않는다.
- 모든 포함 화면은 데스크톱 기준으로 일관된 레이아웃, 로딩·빈·오류·성공 상태를 제공한다.
- 상태 배지와 정렬은 서버 계약과 MVP 정책을 따른다.
- 랜드마크·비콘의 정보 수정은 불변 식별자를 기준으로 이루어진다.
- 가입 신청, 승인, 건물/층 관리, 설계도 업로드, 정보 입력, 연결자 관리의 주요 흐름을 키보드로도 완료할 수 있다.
